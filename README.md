# Alvik Sim Hub

สนามจำลองสำหรับการอบรม Arduino Alvik เพื่อเตรียมการแข่งขัน Arduino Day เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งและไม่ต้องต่ออินเทอร์เน็ต

## หน้าใช้งาน

| หน้า | ใช้ทำอะไร |
|---|---|
| สนามแข่ง C++ | เขียนโค้ด Arduino C++ ด้วยชื่อฟังก์ชันของ library `Arduino_Alvik` แล้วดูผลบนสนามเกม Lift & Park |
| Tap Planner | จิ้มบนสนามเพื่อสร้างคำสั่ง `move()` และ `rotate()` แล้วส่งไปรันในสนามแข่ง C++ |
| LineTrack | เลื่อนหุ่นยนต์ออกจากเส้น แล้วดูค่า IR (Infrared) 3 ตัวและ state ของโค้ดเดินตามเส้น |

ลิงก์ตรงไปแต่ละหน้า: `index.html#arena`, `index.html#tap`, `index.html#linetrack`

กด `F` เพื่อเข้าโหมดนำเสนอ (ซ่อนแถบด้านบนและเต็มจอ) และกด `Esc` เพื่อออก

## ข้อจำกัด

สนามจำลองไม่ได้จำลองแรงเสียดทาน มอเตอร์ หรือเซ็นเซอร์จริง ค่าเวลาและระยะเป็นค่าประมาณ ควรทดสอบกับหุ่นยนต์จริงก่อนแข่งทุกครั้ง
